\# AMPDA



> Autonomous Music Production \& Distribution Agent



AMPDA is a modular AI platform for autonomous music creation, production planning, artwork generation, metadata generation, distribution, and analytics.



\---



\# Vision



Generate, evaluate, improve, package, publish, and analyze complete music releases with minimal human intervention.



\---



\# Current Features



\- CLI

\- Orchestrator

\- Agent Runtime

\- Native Ollama Support

\- Lyrics Generation

\- Music Prompt Generation

\- Artwork Prompt Generation

\- Metadata Generation

\- Project Export

\- Workflow Execution

\# Development



Install dependencies



```bash

pnpm install

```



Build everything



```bash

pnpm -r build

```



Generate a song



```bash

node .\\apps\\cli\\dist\\index.js create-song `

&#x20; --title "Still Here" `

&#x20; --genre "Hip Hop" `

&#x20; --mood "Dark" `

&#x20; --theme "Overcoming adversity"

```
